# How to Run the UI

1. Open the `index.html` file.  
2. In the top-right corner, right-click the **Raw** button and open it in a new tab.  
3. Add the HTML preview URL in front of the Raw file’s URL to view the rendered UI.
  Like this
```
https://htmlpreview.github.io/?
```
  it  will look something like this
```
https://htmlpreview.github.io/?https://raw.github.ibm.com/loz/Utilities/refs/heads/master/external_table/index.html?token=GHSAT0AAAAAAACYBTGHD3UAHFXGRMIGCFBI2IMRFHQ
```
